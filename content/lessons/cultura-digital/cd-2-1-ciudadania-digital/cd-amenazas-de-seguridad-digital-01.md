# amenazas de seguridad digital

## objetivo

distinguir amenazas digitales por la forma en que actúan y el daño que buscan causar.

## explicación

una amenaza digital busca obtener información, manipular a una persona, dañar un dispositivo o bloquear sus datos.

- phishing: mensaje o sitio que suplanta a una entidad confiable para engañar y obtener contraseñas, datos bancarios u otra información.
- grooming: acercamiento de una persona adulta a una persona menor de edad mediante engaño o manipulación para obtener control, información íntima o un encuentro.
- malware: programa malicioso que afecta un dispositivo, espía, altera información o permite acceso no autorizado.
- ransomware: tipo de malware que bloquea o cifra archivos y exige un pago para recuperarlos.

el canal no define por sí solo la amenaza. un correo puede ser legítimo o ser phishing; identifica qué conducta intenta provocar y qué daño se produce.

## ejemplo resuelto

una persona descarga un supuesto programa gratuito desde un sitio desconocido. después, sus documentos quedan cifrados y aparece un mensaje que exige dinero para recuperarlos.

1. el problema inicia con la instalación de un programa malicioso.
2. los archivos quedan cifrados y se exige un pago.
3. se trata de ransomware, que es un tipo específico de malware.

## error frecuente

no confundas phishing con malware. el phishing usa engaño para que la víctima entregue información o abra un enlace; el malware es un programa que se ejecuta y causa daño. un caso puede usar ambos, pero la descripción indica cuál se debe identificar.

## práctica guiada

1. intenta primero: llega un mensaje que imita a un banco y pide ingresar datos en un enlace urgente. ¿qué amenaza describe?
   respuesta: phishing, porque suplanta a una entidad para obtener información mediante engaño.
2. intenta primero: una persona desconocida crea confianza con un adolescente, le pide imágenes privadas y propone encontrarse sin avisar a su familia. ¿qué amenaza describe?
   respuesta: grooming, porque hay manipulación dirigida a una persona menor de edad para obtener control o información íntima.
