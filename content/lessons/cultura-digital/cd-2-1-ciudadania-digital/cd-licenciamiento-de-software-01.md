# licenciamiento de software

## objetivo

distinguir freeware, shareware y software de código abierto por sus condiciones de uso y distribución.

## explicación

una licencia establece cómo puede usarse, copiarse, modificarse o distribuirse un programa. que un programa sea gratuito no significa que todas sus condiciones sean iguales.

- freeware: puede usarse sin pagar una cuota. normalmente no permite acceder ni modificar su código fuente.
- shareware: se ofrece para probarlo durante un tiempo o con funciones limitadas. después puede requerir pago para continuar o desbloquear todas sus funciones.
- software de código abierto: permite consultar el código fuente y, conforme a su licencia, estudiarlo, modificarlo y redistribuirlo. puede ser gratuito o tener costos de soporte o distribución.

para clasificar un caso, busca la condición principal: uso gratuito, periodo de prueba o acceso al código fuente.

## ejemplo resuelto

un programa de edición permite usar todas sus funciones durante treinta días. al terminar ese periodo, solicita comprar una licencia para guardar proyectos nuevos.

1. el programa puede probarse antes de pagarse.
2. el acceso completo está limitado a un periodo de prueba.
3. por lo tanto, es shareware.

## error frecuente

no confundas software gratuito con software de código abierto. un programa puede ser freeware y mantener su código cerrado; el código abierto se identifica por los permisos sobre su código fuente, no solo por el precio.

## práctica guiada

1. intenta primero: una aplicación puede descargarse y usarse sin costo, pero su empresa no permite ver ni modificar el código. ¿qué tipo de licencia describe mejor el caso?
   respuesta: freeware. el uso es gratuito, pero no hay acceso al código fuente.
2. intenta primero: un programa publica su código y permite que la comunidad lo adapte y distribuya bajo las condiciones de su licencia. ¿qué tipo de software es?
   respuesta: software de código abierto, porque permite estudiar y modificar el código conforme a la licencia.
