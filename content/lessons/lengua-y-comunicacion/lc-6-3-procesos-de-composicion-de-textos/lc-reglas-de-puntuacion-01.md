# Reglas de puntuación

## Objetivo

Identificar qué signo de puntuación falta en un espacio de un texto, según el sentido que ese espacio debe tener.

## Explicación

Cada signo de puntuación cumple una función distinta dentro de un texto:

- **Punto**: separa dos enunciados independientes dentro de un mismo párrafo.
- **Dos puntos**: se usan antes de una cita textual, antes de una enumeración, o para anunciar una explicación.
- **Coma**: separa elementos de una enumeración, o intercala información adicional dentro de un enunciado.
- **Apertura y cierre de interrogación**: enmarcan una pregunta directa.
- **Apertura y cierre de exclamación**: enmarcan una expresión de sorpresa, alegría, enojo u otro afecto.

El criterio para identificar el signo faltante es leer el sentido completo del fragmento: si separa dos ideas completas, es punto; si anuncia una cita textual, son dos puntos; si expresa una emoción, son signos de exclamación; si plantea una pregunta directa, son signos de interrogación.

## Ejemplo resuelto

Un enunciado dice: "La alarma sonó a medianoche___ Todos los vecinos salieron a la calle. El vigilante gritó___ ¡Incendio en el edificio___".

1. El primer espacio separa dos ideas completas e independientes: necesita un punto.
2. El segundo espacio anuncia lo que el vigilante dijo textualmente: necesita dos puntos.
3. El tercer espacio cierra una expresión que ya empieza con signo de apertura de exclamación ("¡Incendio..."): necesita el cierre de exclamación.

## Error frecuente

No confundas el punto con los dos puntos: el punto separa dos enunciados independientes que no dependen uno del otro; los dos puntos se usan cuando lo que sigue explica, cita textualmente o enumera lo que se acaba de anunciar.

## Práctica guiada

1. Intenta primero: "El profesor preguntó___ ¿Alguien terminó la tarea___". ¿Qué signos faltan en cada espacio?
   Respuesta: dos puntos (para anunciar la pregunta textual) y cierre de interrogación (porque ya hay una apertura antes de "Alguien").
2. Intenta primero: "Compró frutas, verduras___ pan y leche para la semana." ¿Qué signo falta?
   Respuesta: una coma, porque separa elementos de una enumeración.
